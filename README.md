# Shotbox

macOS 截图标注工具，Shottr 的开源等效实现。Swift + AppKit + ScreenCaptureKit，MIT 许可。

Shottr 本身不开源，也不提供可复用的 API。本项目不是它的分支或反编译产物：`SPEC.md` 记录的是从 Shottr 1.9.3 的公开元数据（Info.plist、用户配置默认值）和界面行为中整理出的功能规格，代码全部独立编写。目标是提供一个可读、可改、可发布的替代品。

## 已实现

**截图**
- 区域截图：多显示器覆盖层、暗色遮罩、实时像素尺寸标签、四角手柄、Enter 或双击确认、Esc 取消
- 全屏截图
- **滚动长截图**：在选区内向下滚动，逐帧按行哈希找重叠并拼接；停止滚动约 1.5 秒自动收尾，上限 20000 像素
- 重开上次选区：记住上次的屏幕与矩形，一键重拍同一区域

**编辑器**
- 标注工具：矩形、椭圆、箭头、直线、自由笔、文字、序号徽章、高亮、马赛克、聚光
- 选择工具：点选对象、拖动移动、Delete 删除
- 撤销 / 重做（60 步）
- 颜色、线宽可调；聚光与马赛克始终绘制在标注之下

**输出与系统集成**
- 复制到剪贴板（Enter / ⌘C）并自动关闭
- 保存为 PNG（⌘S）
- 贴图：置顶浮动窗口，双击或 Esc 关闭（⌘P）
- OCR：Vision 框架，中文优先（⌘E）
- 取色：读取画布像素并复制 HEX
- 全局快捷键（Carbon，无需辅助功能授权）
- 菜单栏常驻，权限状态直接显示在菜单里

**开发自测**
- `--selftest`：不依赖屏幕权限，验证标注渲染、PNG 导出、取色，以及滚动拼接（合成 3000 行页面逐帧滚动后逐像素比对）
- `--editor-demo`：打开一个带示例画布的编辑器窗口，用于检查布局
- `--capture-test <path>`：抓主屏并写文件，用于验证 ScreenCaptureKit 与屏幕录制权限

## 构建

要求 macOS 14+ 与 Xcode 命令行工具。

```bash
./build.sh          # 编译 release、组装 Shotbox.app、ad-hoc 签名
open Shotbox.app
```

`build.sh` 只做本地 ad-hoc 签名，适合自用。要发布给他人，需要 Developer ID 证书签名并公证，否则首次打开会被 Gatekeeper 拦截。

## 首次使用

1. 打开 Shotbox.app，菜单栏出现相机图标
2. 菜单里若显示「⚠️ 屏幕录制权限未授予」，点它跳到系统设置
3. 在「隐私与安全性 → 屏幕录制」勾选 Shotbox，然后**退出并重新打开**应用
4. 按 ⌘⇧2 框选，Enter 进入编辑器

## 快捷键

| 动作 | 快捷键 |
| --- | --- |
| 区域截图 | ⌘⇧2 |
| 全屏截图 | ⌥⌘3 |
| 滚动长截图 | ⌃⇧2 |
| 重开上次选区 | ⌥⇧2 |
| 从剪贴板识别文字 | ⌃⌘2 |

滚动截图不需要按键结束：选好区域后开始向下滚动，停止滚动约 1.5 秒自动拼接完成并进入编辑器。

编辑器内：`Enter` 复制并关闭、`Esc` 关闭、`⌘Z` / `⌘⇧Z` 撤销重做、`⌘S` 保存、`⌘P` 贴图、`⌘E` 识别、`Delete` 删除选中对象。

## 代码结构

```text
Sources/Shotbox/
  main.swift      启动入口与 --selftest 分支
  App.swift       菜单栏、快捷键注册、截图流程编排
  HotKey.swift    Carbon 全局快捷键
  Capture.swift   ScreenCaptureKit 抓屏、选区覆盖窗口
  Model.swift     工具枚举、标注模型、渲染器
  Editor.swift    画布视图、编辑器窗口与工具栏
  ScrollCapture.swift  滚动长截图的拼接器、提示条与会话
  Services.swift  导出、OCR、权限、贴图窗口
  SelfTest.swift  非交互自测
```

渲染器 `Renderer` 同时服务屏幕绘制和导出，保证所见即所得：屏幕按点坐标画，导出时用 CTM 缩放到像素尺寸。
